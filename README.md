# Dasindu Sanujana — Portfolio

A responsive multi-page portfolio built with plain HTML, CSS and JavaScript. The visual identity uses a dark navy foundation and electric-blue accents.

## Pages
- Home — `index.html`
- About — `about.html`
- Projects — `projects.html`
- Digital Lab — `lab.html`
- Contact — `contact.html`
- Custom not-found page — `404.html`

## Toolkit
HTML5, CSS3, JavaScript, Node.js, Figma, Firebase, Cloudflare, GitHub, Electron, OpenAI, Notion and Git. Technology marks are displayed with the Simple Icons CDN.

## Navigation behaviour
The navigation is solid, dark and full-width at the top of each page. After scrolling, it becomes a centered rounded glass panel with blur. Returning to the top restores the solid full-width state. Mobile navigation uses a dedicated accessible toggle.
