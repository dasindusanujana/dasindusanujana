# DASINDU — OBSIDIAN Portfolio

A cinematic, responsive single-page portfolio for Dasindu Sanujana.

## Design direction
- Obsidian dark visual system with electric-blue accents
- Cinematic orbital hero artwork built with CSS
- Editorial About and Selected Work sections
- Technology cards grouped by category
- Split contact section and editorial footer
- Responsive navigation and desktop custom cursor

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- GSAP + ScrollTrigger (progressive enhancement via CDN)
- Google Fonts (Manrope and DM Mono)

## Run locally
Open `index.html` in a browser or use a static development server.

## Deployment
Designed for Cloudflare Pages with the repository root as the build output directory. No build command is required.

## Notes
- Selected Work entries are explicitly marked Coming Soon placeholders.
- The contact form opens the visitor's email application using a mailto link; it does not store or transmit form data to a server.
- External profile links are only included where a verified URL is available.
