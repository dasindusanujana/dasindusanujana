# Dasindu Sanujana — Portfolio

Custom dark editorial portfolio built with semantic HTML, CSS and vanilla JavaScript.

## Features
- Solid top navigation that becomes a centered glass navigation after scrolling
- Responsive mobile navigation
- Abstract animated hero artwork; no personal photography
- Project filtering and Ctrl/Cmd + K quick navigation
- Scroll progress and reveal motion with reduced-motion support
- Contact form prepares a message in the visitor's email app; it does not submit to a backend
- SEO metadata, sitemap, robots.txt, favicon and web manifest

## Local preview
Run a static HTTP server from the repository root. ES modules are not required; pages use plain scripts.

## Deployment
Deploy the repository root as a static site. No build command is required.

Project descriptions and experience figures are based on information supplied by the site owner.
